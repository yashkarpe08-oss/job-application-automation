# Candidate profile (template)

Copy this file to `profile/profile.md` and fill it in. `profile.md` is git-ignored
so your contact details stay private. If `profile.md` is missing, the agents use
the profile in the `job-application-assistant` skill instead.

## Identity
- Name, location, phone, email, LinkedIn, languages

## Education
- Degree, institution, dates, result, project, top modules

## Experience
- Title, company, location, dates
  - Achievements with exact numbers (the agents never change or invent numbers)

## Skills
- Primary / secondary / domain / software

## Known gaps
- Things you do NOT have, so the agents never claim them
